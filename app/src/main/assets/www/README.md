# نيرو (Nero): محرر برمجة بالعربي

اكتب HTML وCSS وJavaScript بكلمات عربية، وبضغطة زر يتحول كودك لإنجليزي حقيقي (وبالعكس).

## الملفات
- `index.html`: التطبيق كامل بملف واحد (هذا الملف الي ترفعه على «بيور تطبيق» مع الأيقونة).
- `icon-512.png` و `icon-192.png`: أيقونة التطبيق.
- `worker/nero-worker.js`: وسيط Cloudflare يخبي مفاتيح OpenRouter (اختياري، شوف تحت).
- `src/`: الكود المصدري. لإعادة البناء: `cd src && python3 build.py` (ينتج `nero.html` انسخه كـ `index.html`).
  - فحوصات: `node t2.js` و `node rt.js` و `node audit.js` و `node courseTest.js`.

## المعلم الذكي (مجاني)
التطبيق ما فيه أي مفتاح داخله. خيارين:
1. **وسيط Cloudflare (الأفضل إذا التطبيق عام):** سوّ Worker والصق `worker/nero-worker.js`، وأضف Secret اسمه `OR_KEYS` فيه مفاتيح OpenRouter المجانية (openrouter.ai/keys) يفصل بينها فراغ. ثم الصق رابط الـ Worker بإعدادات التطبيق (خانة «رابط الوسيط») أو ضعه بالثابت `NERO_PROXY` داخل `src/app.js` قبل البناء.
2. **مفتاح المستخدم:** كل مستخدم يلصق مفتاحه المجاني بالإعدادات، وينحفظ على جهازه فقط.

لا ترفع مفاتيح حقيقية على جيتهاب أبداً.

## مساعد الكتابة
اكتب حرف أو أكثر وتطلع كلمات حسب مكانك بالكود، مع مقابلها الإنجليزي. قوالب جاهزة ⚡ (صفحة كاملة، نموذج، جدول، شبكة، متجاوب، حدث، جلب ...). Tab يقبل أول اقتراح. وتطلع أيضاً كلمات من ملفك نفسه (أسماء المتغيرات والفئات).
